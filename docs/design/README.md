# 더스트 제로 제작 기준 — Claude 진입점

사용자가 제공한 「오퍼레이션: 더스트 제로 유니티 제작 가이드」를 기존 CCGS에 통합했다.
문서 표제는 2026-10-14이지만 내용에는 10.14-k와 10.15-b 변경사항이 포함되어 있다.
원문은 `sources/production-guide-2026-10-14.txt`에 바이트 그대로 보존했다.
이후 신규 **10.15-h** 빌드가 제공되었다. **NEW-BUILD.md를 먼저 읽고 현재 추가 개발의 기준으로 사용한다.**
아래10.14-d는 프로젝트 내부의 구버전 사본 설명이며 최신 원본을 뜻하지 않는다.

## 먼저 구분할 것

- **현재 기준본:** 프로젝트의 `GameData/`는 확인 당시 웹 빌드 **10.14-d**, JSON **22개**다.
  현재 구현을 재현/회귀 검사할 때 사용하는 자료다. 파일이 존재한다는 것은 Unity 구현 완료 증거가 아니다.
- **목표 설계:** 새 가이드에 명시된 무한 대청소, 전투 중 강화, 조각 돌파, 상점/시즌 패스,
  SD Spine 아트 등은 이식의 목표/후속 단계로 관리한다. 현재 원본에 이미 있다고 가정하지 않는다.
- **문서 내 불일치:** `SOURCE-DECISIONS.md`를 읽는다. 구버전 숫자를 최신 목표에 섞지 않는다.
- **이번 작업 범위:** 하네스와 문서 정리. 게임 코드·데이터·패키지를 목표 설계로 변경한 작업은 아니다.

## 작업별 읽을 문서

| 작업 | 읽을 기준 |
| --- | --- |
| 이번 추가 개발의 원본/우선순위 | `NEW-BUILD.md` |
| 어떤 버전/수치를 적용할지 | `SOURCE-DECISIONS.md` → 원문 해당 항목 → 실제 테이블/코드 |
| 전투·성장·생존·상점 | `GAME-SPEC.md` |
| 데이터·저장·Unity 구조 | `IMPLEMENTATION.md` |
| 캐릭터·Spine·연출·오디오 | `ART-AUDIO.md` |
| 구현 순서·완료 조건 | `MILESTONES.md` |
| 실제 검증 | `../qa/GAME-QUALITY.md` 및 `/game-quality` |
| 수치 상세/빠진 원문 | `sources/production-guide-2026-10-14.txt` |
| 현재 자료 목록과 해시 | `BASELINE-INVENTORY.json` (정적 스냅샷; 작업 때 다시 확인) |

## Claude 작업 규칙

작업마다 **기준본 재현 / 목표 설계 반영 / 출시 연동** 중 범위를 밝힌다.
새 기획이 명확히 기술된 부분은 목표로 기록하고, 수치·스키마·진입점이 불명확한 부분은
임의로 발명하지 말고 미정 항목으로 남긴다. 독립적으로 가능한 구현/검증은 계속한다.
현재 파일과 테스트를 조사하여 이어가며, `Assets/_Game` 예시나 M1 때문에 프로젝트를 다시 만들지 않는다.
목표 단계가 문서에 있다는 이유로 결제·광고 서비스 구매, 배포, 저장 초기화, 엔진 변경을 실행하지 않는다.
자세한 문서는 관련 작업 때 읽는다. 이 인덱스만으로 모든 수치를 추측하지 않는다.
