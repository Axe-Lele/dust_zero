# 아트·연출·오디오 제작 기준

제공 가이드의 목표 아트 방향이다. 현재 HTML 캡처/추출 스프라이트와 동일하다는 뜻이 아니다.
원문에서 '이전 대화의 프롬프트'는 제공되지 않았으므로 해당 프롬프트를 읽었다고 가정하지 않는다.

## 스타일과 제작 순서

성인 캐릭터의 인게임 SD는2.3등신, 소환/상세는 성인 비율 일러스트.
설정 시트(삼면도/일러스트/색상 HEX)로 형태·팔레트를 정하고 같은 캐릭터의 결과물에 유지한다.
가전 기능을 모티프로 사용하고 실제 브랜드/제품 디자인은 사용하지 않는 원문의 방향을 따른다.

1. 청소기1종부터 스타일 시트→기본 포즈→파츠→PSD→Spine→Unity를 끝까지 확인.
2. 기본 포즈 가이드:1024×1024 A포즈,3/4 우측, 발y≈900, 팔다리 겹침 최소화.
3. 파츠15~20장+표정, 가려진 부분 약15% 여유. 파일 생성만으로 정렬/회전 품질이 확인된 것은 아니다.
4. PSD 영문 레이어와 실제 bone명 정리. PhotoshopToSpine 태그 문법은 공식 도구 버전을 확인.
5. 실제 뼈/슬롯 이름을 기준으로 애니메이션 제작. 생성 JSON은 에디터 임포트/변형/관절 검증 필요.
6. Spine 에디터와 맞는 spine-unity 런타임, SkeletonDataAsset/프리팹, 텍스처 최대2048,
   타일1칸 크기/발 위치/정렬 레이어/아틀라스 번짐 확인.
7. 청소기 경로가 검증되면 실제 unit ID 집합의 나머지8종으로 확장한다.

원문의 Gemini/Photoshop/Clip Studio/Spine은 제안 파이프라인이다.
구매·계정 연결·라이선스 보유를 가정하지 않는다. 사용할 수 없는 도구 단계는 미확인으로 기록하고
독립적인 스프라이트/프리팹 작업은 진행할 수 있다. 임시 스프라이트를 최종 Spine 결과로 표시하지 않는다.

크로마 색은 원문 제작 배경 제안이다. 게임용 최종 파츠/스프라이트는 투명 배경으로 정리하고 색 번짐을 검사한다.

## 애니메이션/피드백

배치 deploy→idle, 평타 attack, 스킬 skill_start→skill_loop,
과열 overheat 반복→recover, 철수 retreat, 피격 hit를 매핑한다.
과열/철수로 중단될 때 이전 스킬 이펙트/루프를 정리하고 풀 재사용 시 상태를 초기화한다.
피해 타이밍은 BattleSim이 결정한다. 애니메이션/투사체/이벤트는 이를 표현한다.

피격 파편·데미지 숫자·직선/포물선 투사체·스킬 입자·처치·과열/복구·보스 배너·화면 흔들림·
클리어 색종이를 넣되 조준/배치 타일과 전투 정보를 가리지 않도록 화면에서 확인한다.
적 수백 마리는 Spine을 적용하지 않고 스프라이트와 풀을 사용한다.

## BGM와 효과음

- 목표곡3개: lobby.mp3/battle.mp3/survival.mp3. 구 GameData에는 없지만 신규10.15-h의 audio/에 제공되었다.
- 원문 특정 파일 기준 루프: 로비9.9~29.6초/전투11.4~71.4초/대청소11.8~150.7초.
  실제 파일을 받으면 길이/샘플과 귀로 확인하며 다른 곡에 이 값을 복사하지 않는다.
- 인트로1회+루프, 전환 약1초 크로스페이드, 전투/대청소 매 판 처음부터, 로비 이어서,
  앱 비활성 시 정지/복귀. BGM 음량0~100/음소거(opt.bgm/opt.mute) 저장.
- Unity는 AudioSource2개 교차 재생과 샘플 기반 루프를 검토한다. 원문 RMS−18dBFS,
  끝2.5~3초 블렌딩은 원본 파일 편집 참고이며 모든 오디오의 강제 기준이 아니다.
- 효과음26종은 Web Audio 합성 정의를 렌더링한 WAV 또는 새 제작으로 대체한다.
  버튼/배치/강화/멀티탭/스킬/처치/누수/과열/보스/승패/성장/소환 등 실제 이벤트에 매핑,
  동일 음 최소 간격과 중첩 상한으로 과도한 소리를 방지한다.
- 대청소 대체 칩튠:150BPM/A단조/16마디25.6초 반복, 펄스 리드·아르페지오·삼각 베이스·노이즈 드럼,
  설정에서 곡 선택, 전환/루프/음량을 실제 청취한다. 원문 RMS약−23dB도 참고값이다.
- 음악/이미지 생성 도구의 상업 이용 문장은 원문의 미검증 라이선스 주장이다.
  실제 사용 파일의 출처·생성 시점·계정 플랜·당시 조건·이용 증빙을 별도로 확인한다.

완료 증거는 임포트 성공뿐 아니라 실제 화면/애니메이션 전환/오디오 청취 결과다.
