### 데이터가 틀렸던 것

이식 전 화면은 별 조건을 **퍼센트**로 썼다 — `청결도 60% 이상`, `청결도 100%`.
원본은 `config.starLifeMin = [1, 6, 10]` 의 **남은 생명 수**다. `lifeMax` 가 10이라
우연히 비율이 맞아 보였을 뿐, 표가 바뀌면 바로 어긋난다. 전투 HUD 도 같은 이유로
퍼센트 바에서 숫자로 고쳤으므로, 브리핑 칩과 결과 화면도 숫자로 맞췄다.

## 원본과 다른 점 (의도한 것)

- **MVP 한 줄은 원본에 없다.** 이미 만들어 둔 것이라 지우지 않고 카드 맨 아래
  한 줄로 남겼다. 처치 수가 가장 많은 가전을 고른다.
- 대청소 결과의 아래 줄에서 `오늘 크리스탈 x/y · 남은 판 n/3` 은 아직 안 넣었다.
  그 수치를 `SurvResult` 가 들고 있지 않다 — 넣으려면 시뮬레이션 쪽을 먼저 고쳐야 한다.
- 전투 결과의 `시즌 패스 경험치 +N` 줄과 전력 스킬 해금 안내는 아직 없다.

### 고치는 중에 또 밟은 것

26pt 제목을 원본의 36px 줄에 그대로 넣었더니 **TMP 가 줄을 통째로 버렸다.** 이 세션에서
여러 번 밟은 함정이다 — CSS 는 line-height 로 글자를 자르지만 TMP 는 자르지 않고 아예
그리지 않는다. 42px 로 올려 해결했고, 빈 라벨 게이트가 잡아 줬다.

### 같이 돌린 다른 세션의 테스트

`PauseMenuOpensFromExitAndDimsTheTray` 1개가 실패한다. **이 작업의 것이 아니다** —
다른 세션이 추가 중인 일시정지 메뉴 테스트이고(`battle.pause.*` 문자열, 트레이
CanvasGroup, `05b-battle-pause-menu` 증거), 실패 내용도 "전투가 애초에 진행되지
않았습니다" 로 그쪽 기능의 타이밍 문제다. 손대지 않았다.
