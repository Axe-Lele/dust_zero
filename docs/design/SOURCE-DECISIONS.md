# 출처 차이와 적용 기준

이 문서는 원문을 조용히 고쳐 쓴 것이 아니라, 현재 파일과의 차이 및 하네스의 해석을 기록한다.
원문 전체와 현재 자료 목록은 같은 폴더의 sources 및 BASELINE-INVENTORY.json에 있다.
후속 업데이트: 신규10.15-h가 제공되어 일부 자료 부족이 해소되었다. NEW-BUILD.md를 먼저 읽는다.
아래 표의 '현재 파일'은 기존 GameData10.14-d 스냅샷이며, 최신 원본은 NEW-BUILD.md의 경로다.

## 우선순위

1. 사용자가 이후 명시한 결정.
2. 현재 추가 개발은 신규10.15-h가 기준이다. 10.14-d는 구버전 회귀/마이그레이션 검증에 한정한다.
3. 기준본 재현은 그 버전의 실제 코드/엑셀/JSON을 대조한다. 편집 원본은 엑셀이며 JSON은 생성 결과다.
4. 목표 반영은 가이드의 구체적인 변경 항목을 요구사항으로 사용한다. 후속 버전 원본이 없으면
   정확한 누락 수치/스키마는 미확정으로 기록하고, 별도 변경과 테스트로 반영한다.
5. 일반 하네스 예시보다 이 프로젝트 문서/경로를 우선한다.

## 남겨둔 결정과 미확인

- 초기 정리 때는10.15-b 전체 자료가 없었으나 이제10.15-h가 제공되었다. 최신 수치는 해당 실제 데이터로 확인한다.
- 레벨 30 이후 비용 행, 시즌 보상 모든 행, 상점 전체 상품 ID/문구 키 등 빠진 구체값은
  제공 자료에 있는지 먼저 확인하고, 없으면 미정으로 남긴다.
- 시작 시즌 시각/시간대, 일일·주간 초기화 기준, 구독 누락일 처리, 시즌 교체/구매 복구 정책은 명시 필요.
- 첫 클리어 보상 반복 금지와 재클리어 패스 XP 30은 서로 다른 보상이다. 두 규칙을 혼동하지 않는다.
- 별 조건의 미션형 변경, 부품 장착/신모델 각성, 추가 계열 시너지, 출시 플랫폼 순서는 열린 기획이다.
- 원문 후반의 BM '열린 질문'과 구체 상점안은 함께 보존한다. 상점안은 프로토타입 목표이며
  출시 상품/가격/정책이 최종 승인됐다는 뜻이 아니다.
- 법률·계약·Unity/Spine/생성 도구·음악의 라이선스 문장은 제공자의 점검 목록이다.
  현재 약관을 검증한 결론으로 재사용하지 말고 실제 도입/출시 때 공식 출처와 계정 권리를 확인한다.
