# 관리툴 공유 — 지금은 파일, 나중에 네트워크

기획자에게 관리툴만 떼어 보내고, 고쳐 온 것을 프로젝트로 다시 합치는 방법.

## 왜 파일을 통째로 주고받지 않는가

**엑셀은 병합이 안 된다.** 두 사람이 같은 `02_Unit.xlsx` 를 고치고 한쪽이 파일을 보내면,
그 사이 이쪽에서 고친 것이 전부 날아간다. 되돌릴 방법도 없다.

그래서 파일이 아니라 **기준점 대비 바뀐 행만** 작은 패치로 옮긴다. 합칠 때는 세 쪽
(기준점 · 받은 것 · 지금 프로젝트)을 비교해서, 양쪽이 같은 칸을 서로 다르게 고쳤으면
덮어쓰지 않고 **충돌로 표시한 뒤 사람이 고르게** 한다.

그래도 **한 번에 한 사람만 고치는 것**을 권한다. 충돌 검사는 사고를 막아 줄 뿐,
두 사람의 수정을 합쳐 주지는 못한다.

## 층을 나눈 이유 (네트워크 이관)

| 파일 | 하는 일 | 네트워크로 바꿀 때 |
| --- | --- | --- |
| `tools/dz_patch.py` | 무엇이 바뀌었는지 계산 · 충돌 판정 · 합치기 | **그대로** |
| `tools/dz_review.py` | 바뀐 내용을 화면에 그림 | **그대로** (웹 화면도 같은 Plan 을 받는다) |
| `tools/dz_transport.py` | 패치를 옮김 | **여기만 고친다** |
| `tools/dz_share.py` | 위 셋을 엮는 명령줄 | 거의 그대로 |

`Transport` 는 네 가지만 안다 — `push` / `list` / `fetch` / `ack`.
지금은 `FileTransport` 가 폴더 하나로 구현한다(그 폴더가 공유 드라이브면 사실상
자동 동기화처럼 쓸 수 있다). 서버를 붙일 때는 `HttpTransport` 의 네 메서드만 채우면
되고, 끝점 네 개가 전부다:

```
POST   {base}/patches            patch.json + 그림  -> {"id": ...}
GET    {base}/patches?since=ID   머리말 목록
GET    {base}/patches/{id}       zip 본문
POST   {base}/patches/{id}/ack
```

서버를 붙이면 **편집 잠금**을 서버가 강제하는 편이 낫다. 엑셀이 병합되지 않는다는
사실은 전송을 바꿔도 달라지지 않는다.

## 쓰는 법

### 개발 쪽 — 보낼 묶음 만들기

```bash
python tools/build_studio.py              # exe 를 먼저 갱신
python tools/dz_share.py pack ../보낼폴더
```

묶음에는 exe · 엑셀 · 변환기 · 그림(대기 폴더) · 기준점이 들어간다. Unity 프로젝트는
넣지 않는다 — 그쪽은 열 수도 없고 넣으면 기가 단위가 된다. 약 59MB.

`pack` 은 마지막에 **묶음을 그 묶음의 코드로 열어 본다.** 묶는 중에 프로젝트가 바뀌어
테이블과 변환기가 어긋나면 "보내지 마세요" 라고 말하고 멈춘다. (실제로 겪었다 —
다른 작업이 워크북 이름을 바꾸는 중에 묶여서, 받은 쪽이 저장을 누르는 순간 깨졌다.)

### 기획 쪽 — 고치고 패치 뽑기

```
DustZeroStudio.exe          더블클릭. 폴더 안에서 실행해야 한다.
python GameData/tools/dz_share.py export 보낼패치.dzpatch
```

패치는 13KB 수준이다. 이 파일만 보내면 된다.

### 개발 쪽 — 합치기

```bash
python tools/dz_share.py review 보낼패치.dzpatch     # 뭐가 바뀌는지만 본다
python tools/dz_share.py apply  보낼패치.dzpatch --gui
python GameData/tools/sync_to_unity.py
python tools/dz_share.py baseline                     # 기준점 다시 찍기
```

`--gui` 를 붙이면 확인 창이 뜬다. 숫자는 전/후와 증감을 같이 보여 준다:

```
공격력   0 → 88   (▲ +88)
배치 비용 9 → 7   (▼ -2)
가격  5900 → 5500 (▼ -400)
```

충돌은 빨갛게 펼쳐져 나오고 **기본으로 꺼져 있다.** 줄을 눌러 켜고 끌 수 있고,
끈 항목은 합치지 않는다. 명령줄에서 `--force` 를 주면 충돌도 받은 값으로 덮어쓴다.

## 검사

```bash
python tools/share_selftest.py      # 주고받기 한 바퀴 25건
python tools/studio_roundtrip.py    # 불러오기→저장이 테이블을 바꾸지 않는가
```

`share_selftest.py` 가 보는 것: 바뀐 것만 담기는가 · 전/후와 증감이 맞는가 ·
합치면 반영되는가 · **양쪽이 고친 칸을 덮어쓰지 않는가** · 끈 항목이 빠지는가 ·
그림이 실려 가는가 · 확인 창의 '적용' 버튼이 창 안에 있는가 · 네트워크 전송이
조용히 아무 일도 안 하는 대신 분명히 막히는가.

## 아직 안 된 것

- 맵을 **새로 만들거나 지우는** 것은 안 된다. 있는 맵의 타일과 경로만 고친다.
- 네트워크 전송(`HttpTransport`)은 뼈대만 있고 호출하면 막힌다.
