# 게임 규칙과 목표 기능

수치는 제공 가이드에서 정리한 요구사항이다. 실제 편집은 엑셀/테이블에서 하고 C# 상수로 복제하지 않는다.
신규10.15-h가 들어왔으므로 현재 추가 개발의 정확한 수치/구현 동작은 NEW-BUILD.md의 원본을 우선한다.
현재 10.14-d와 다른 항목은 SOURCE-DECISIONS.md에 따라 목표 변경으로 취급한다.
가전별 전체 스탯, 적 스탯, 상품 가격의 원문은 `sources/production-guide-2026-10-14.txt`를 참조한다.

## 방향

오리지널 가전 모에화 캐릭터 수집 + 타일 디펜스 + 자동 청소 방치 성장.
가전의 기능이 스킬이 된다. 인게임은 성인 캐릭터를 SD 2.3등신으로 표현하고,
소환/상세는 성인 비율 일러스트를 사용한다. 브랜드·실제 제품 디자인을 복제하지 않는다.
성장 루프는 스테이지 돌파→시급 상승→자동 청소 재화→육성→다음 스테이지다.

## 디펜스

- 7×10 타일, 입구 3개, 거실/주방/욕실의 목표물 방어. 웨이브별 입구 활성화와 스폰 3초 전 경고.
- X 벽/E 목표물 배치 불가. H 가구는 원거리·지원. P/F/W 바닥은 근접.
  F는 과열 +40/초, W는 적 속도 ×1.35 및 냉각 +60/초.
- 입구 앞 2칸과 목표물 바로 앞 칸에는 근접 배치 금지. 지상은 격자 경로/거리장을 사용한다.
  우회형은 우회가 가능하면 가전을 피하고 막혔을 때 저지/대기한다. 직진형의 밀고 들어오는 AI를 구분한다.
  비행은 입구별 고정 경로를 따르고 저지하지 않는다.
- 내부 전력 1=100W. 시작1,000W, 회복100W/초, 상한9,900W.
  발전기당 +35W/초, 풀가동 중 추가 회복2배. 기본 동시배치8, 편성6.
- 철수 기본 환급50%, 재배치12초. 청결도10에서 일반 적1/보스2 누수, 0이면 패배.
  모든 스폰이 끝나고 적이 사라지면 승리. 별 기준 청결도1/6/10, 최고 기록만 저장.
- 근접 저지 범위 자기 위치 ±0.4칸, 보스는 저지2칸. 정원 초과는 통과하지 않고 대기하며
  대기 공격도 과열 피해50%를 준다. 자연 냉각25/초에 선풍기/타일 효과를 더한다.
- 과열 한도 도달 시 5초 정지·저지/대기 해제·공격/스킬 중단·진행 스킬 종료.
  실제 회복 타이밍/냉각은 선택한 버전의 코드와 대조한다. 가전 사망 시스템으로 바꾸지 않는다.
- 자동 스킬 게이지1/초. 공격형은 사거리 내 적, 로봇은 자기 과열50% 이상,
  선풍기는 주변 과열40% 이상, 컴퓨터는 범위 내 공격 가전이라는 발동 조건을 갖는다.
- 성장 배율 `1 + .05*(level-1) + .12*breakthrough`, 공격/과열 한도/냉각/스킬 피해에 적용.
  평타/스킬의 지상·공중 대상은 각각 테이블을 따른다. 컴퓨터 버프는 여러 대 합산.

### 목표: 전투 중 강화와 멀티탭

- 가전별 2단/3단 강화 비용은 배치비×1.0/×1.5, 능력 배율×1.35/×1.75.
  공격·스킬 피해·과열 한도·냉각·발전·버프를 포함한다.
- 3단 근접 저지+1, 원거리/컴퓨터/선풍기 범위+0.4칸, 스킬 충전 감소는 가전별 spMul로 관리.
- 멀티탭 8→9→10칸, 비용2,000/3,500W. 강화 후 철수는 배치+강화 총소비의50% 환급.
- 후반 wave.hpMul 압박은 마지막 웨이브 시각40%부터 최종×3. 1-1과 보스 예외를 보존.
  스테이지 hpMul과 웨이브 hpMul을 별개로 관리한다.

### 가전 9종

| 가전 | 등급/계열 | 핵심 행동 |
| --- | --- | --- |
| 청소기 | R/생활 | 지상 흡입·끌어당김·스킬 중 제한 없는 저지 |
| 로봇청소기 | R/생활 | 자기 과열 제거·공격력2배 |
| 냉장고 | SSR/주방 | 자기 과열 절반·범위 빙결, 평타 지상/스킬 모두 |
| 에어컨 | SR/계절 | 평타 둔화·범위 냉방 지속 피해 |
| 전자레인지 | SR/주방 | 충전 후 가장 앞선 적 주변 폭발 |
| 세탁기 | SSR/생활 | 광역 평타·회오리 지속 피해/넉백, 보스 넉백 차등 |
| 컴퓨터 | SR/디지털 | 평소1.6칸 공격+25%, 스킬2.4칸 공격+60%/공속2배 |
| 선풍기 | R/계절 | 주변 냉각60/초, 터보 즉시 과열40% 감소/냉각3배 |
| 발전기 | R/디지털 | 추가 전력 회복, 스킬800W와 추가 회복2배 |

적 기본7종은 먼지뭉치·기름때·고팡이·초파리와 보스3종이다. 신규 포자 적은 대청소 전용.
정확한 스탯/사거리/쿨타임/피해 계수는 unit/enemy/skill_param의 해당 버전을 참조한다.

## 아웃게임·경제

- 3챕터×5=15스테이지, x-5 보스. 이전 스테이지 클리어로 해금.
  원문 봇 목표/스테이지 길이/승률은 밸런스 초안이며 인간 플레이 검증 완료가 아니다.
- 기본 화면: 홈/스테이지/가전 도감/6슬롯 편성/소환. 목표 홈은 보유 가전이 청소하는 방,
  캐릭터 터치 대사/먼지 터치 청소, 출석·자동 청소·설정·다음 스테이지·대청소 진입.
- 자동 청소는1-1 해금, 최고 스테이지 시급, 최대12시간. 시급 변경 직전 이전 요율로 bank.
  수령은 정수만 지급하고 소수 이월. 시계 역행/조작 대응은 별도 결정.
- 스테이지 반복 클리어의 일반 보상은 없음. 최고 별 갱신과 챕터5/10/15별 보상은 각각1회.
- 레벨업은 코인+계열 부품: 생활 필터/주방 열선/디지털 칩/계절 모터.
  원문 Lv1~9,10~19,20~29 구간에 더해 신규 테이블의30~44 구간도 읽는다. 수치를 임의 생성하지 않는다.
- 목표 돌파는 조각10/20/30/40/50 + 코인2천/5천/1만/2만/4만, Lv상한20→25→30→35→40→45.
  중복 R/SR/SSR은 조각10/15/25, ★5 후 코인1,000. 미보유 영입은 조각20/30/50.
- 소환1회150/10회1,500크리스탈, 마지막1개SR이상 확정, SSR3%/SR17%/R80%.
  가중치 합10,000. 새 가전은 빈 편성 자동 추가, 더 높은 등급이면 대표 교체.
- 시작 지급 그룹9000: 코인2,000/크리스탈1,500/부품각20/청소기·에어컨·선풍기·발전기.
- 목표 출석7칸 순환: 크리스탈50/코인5천/크리스탈50/부품각10/크리스탈50/코인1만/크리스탈200.
  연속 접속 필수 아님. 첫 안내 중 팝업 억제, 첫 접속 팝업과 실제 수령 상태 구분.
- 목표 강제 안내는 새 계정 첫 출동과1-1 이후 청소기 레벨업. UI 키로 포커스하고 다른 입력 차단.
  기존 전투 튜토리얼은 첫 전투별 그룹, 보스/주방/욕실의 첫 전투 조건을 유지.
- 10.15-b 목표 경제: 첫 클리어 크리스탈50/보스150, 15별 보상150/225/300,
  자동청소 크리스탈 시급5~7, 일수입350~450 초안. 세부 행과 실측 검증은 별도다.

## 목표: 무한 대청소

- 리더 청소기/로봇/에어컨, 터치 드래그·WASD/방향키, 자동 공격. 리더 무기Lv1~5.
- 동료 최대4명/Lv1~3, 덱에서 선택. 공격 가전은 따라오며 스킬 사용,
  컴퓨터/선풍기/발전기는 붙어서 강화. 디펜스의 레벨·돌파 위력을 반영한다.
- 레벨업 카드: 주무기/새 동료/동료 강화/이속·최대 내구도. 소진 시 보너스 코인, 회복 카드 없음.
- 무기Lv3 이상+해당 동료 만렙: 청소기+선풍기 토네이도, 에어컨+냉장고 블리자드,
  로봇+발전기 터보. 계열2명은 생활 흡입+30%, 주방 피해+15%, 디지털 간격-15%, 계절 적속도-12%.
- 6분까지 기본 스폰/HP 곡선 이후 유지, 속도분당+7% 상한1.8배,
  2:30 이후 분당 HP+40%/피해+25% 복리. 경험치에 survXpQuad 제곱항.
- 2분마다 보스3종 순환/회차 강화. 먼지 떼1:40부터90초마다, 초파리 떼3:10부터90초마다,
  포위에 탈출 틈을 둔다. 포자 적은1:40 등장, 거리4.6에서2.6초마다 피해9/속도3.6 탄 발사, 근접 시 후퇴.
- 종료는 사망. 5분이 지나도 계속되어야 한다. 오늘/역대 최고 기록과 정지/결과 흐름을 제공.
- 일일 최초 생존 구간 크리스탈: 1/2/3/4/5/7/10/15분에5/10/15/15/20/20/25/40, 총150.
  코인/부품은 하루3판, 처치당코인1/30초당부품1, 30초미만은 횟수 미소모.
  보상 판 리더 조각은 생존1분당1개 최대5라는 원문 규칙을 별도로 검증한다.
- 해금은 개발1-1/기획1-5 차이를 명시. 수백 적은 SpriteRenderer+풀링+격자 버킷.

## 목표: 상점·시즌 패스

실결제/광고는 아직 프로바이더 연동 전이다. 먼저 테스트 프로바이더로 성공/실패/취소/중복 콜백을 검증한다.

- 상점 진입 및 지갑+ 버튼, 무료/수령 가능 빨간 점, 소환 재화 부족→상점 안내.
- 크리스탈 상품6종(60/300/630/1,800/3,700/7,000), 첫구매2배.
  원문 원화 가격은 프로토타입 상품안이며 출시 스토어 확정 가격으로 취급하지 않는다.
- 광고 크리스탈30 하루3회/10분 간격. 일일 광고 코인3천/부품각5/방치2시간,
  크리스탈 소비 일일 상품과 각 제한을 원문 shop_product로 관리한다.
- 패키지: 첫 출동/30일 구독/광고 제거/주간 성장/1-5 기념.
  구독 즉시300+매일100, 재구매30일 연장. 주간은 월요일 초기화, 계정1회·쿨다운·해금 상태 저장.
- 시즌28일/30레벨, 시작Lv1/레벨당XP100. 무료/프리미엄 두 줄, 프리미엄 과거 보상 소급.
  프리미엄 상품안11,000원, 지난 수령과 중복 지급을 구분한다.
- XP: 첫클리어100/재클리어30/대청소30초당10(판당80상한)/출석50/광고10.
  크리스탈150으로1레벨. 무료 크리스탈5레벨마다30, 프리미엄 가전·조각 등은 원문 상세 참조.
- shop_product/pass_level/reward_group으로 비용·보상·제한을 관리한다. 테이블에 없는 상품을 즉석 하드코딩하지 않는다.
