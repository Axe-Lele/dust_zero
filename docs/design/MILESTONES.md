# 제작 단계와 완료 조건

원문의 M1~M7을 기존 프로젝트에 맞춰 정리했다. 각 행은 계획이며 완료 표시가 아니다.
진행 여부는 현재 코드·씬·테스트·실행 증거를 조사해 결정하고 이미 된 작업을 다시 만들지 않는다.
현재 추가 개발은 NEW-BUILD.md의10.15-h를 기준으로 한다. 아래 '목표' 기능 중 상당수는
신규 웹에는 이미 있으며 Unity 이식 여부를 확인해야 한다. 웹 구현 존재와 Unity 완료를 구분한다.

M5-S와 M7-P/R은 가이드 내용을 빠뜨리지 않기 위한 하네스 분류다. 새로 합의된 출시 일정이 아니다.
새 계정 초기화는 격리된 테스트 프로필에서만 수행한다. 현재 개발 단계에는 도형이 가능하지만
M6의 완료 기준이나 출시 완료 보고에서는 임시 자산을 최종 아트로 취급하지 않는다.
자동 청소 알림은 도메인 로직과 분리하여 M5에서 조건을 정하고 실제 기기/권한 연동은 M7-R에서 검증할 수 있다.

## 다음 작업 선택

`/dustzero-guide`로 현황을 읽고 의존성이 충족된 가장 작은 미완성 작업을 고른다.
상태는 NOT_ASSESSED / TODO / IN_PROGRESS / VERIFIED / BLOCKED로 기록한다.
파일명만 발견했으면 VERIFIED가 아니다. BLOCKED에는 필요한 자료/결정을 구체적으로 적는다.
막힌 단계와 독립적인 작업은 계속 진행한다. 이전 체크포인트가 데이터 로더만 언급해도 실제 현재 상태를 우선한다.

## 검증 연결

각 단계 종료 시 `/game-quality`를 실행한다. 보고서에는 현재 재현/목표 구현 버전을 명시한다.
현재 원본과 달라야 하는 목표 변경을 화면/결과 차이라는 이유로 되돌리지 않는다.
성능 목표 FPS·대표 장치·최대 적 수는 측정 전에 명시하며 아직 정해지지 않았으면 미정으로 기록한다.
원문의 봇 밸런스 수치를 사람 플레이 합격 결과로 복사하지 않는다.

## 출시 전 보존할 미결정/점검 항목

플랫폼 순서, 시간 검증 방식, 확장 시스템 우선순위, 미션형 별 조건,
실제 서비스 제공자/상품 정책, 최종 탭 순서, 미제공 후속 테이블과 오디오.
원문의 개인 장비·계정·저장소/회사 자료 분리, 근로계약/상표/엔진·Spine·생성물 권리,
스토어 AI 표시/개인정보 관련 항목은 사용자 점검 과제로 보존한다. 검토 완료로 표시하지 않는다.
원문의 '스토어 업로드'는 출시 단계의 산출물이며 이 문서 추가가 게시 권한을 부여하지 않는다.
