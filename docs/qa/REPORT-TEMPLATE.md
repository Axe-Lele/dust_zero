## 판정

- 전체: UNVERIFIED
- 남은 결함/미확인/임시 자산:
- 다음 작업:

상태는 PASS, FAIL, UNVERIFIED, NOT_APPLICABLE 중 하나다.
필수 FAIL이 있으면 전체 FAIL, 필수 UNVERIFIED가 있으면 전체 UNVERIFIED.
NOT_APPLICABLE은 제외 근거를 적고 최종 게임 전체 검증의 필수 항목에는 적용하지 않는다.
