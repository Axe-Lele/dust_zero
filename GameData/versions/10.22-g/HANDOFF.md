# 오퍼레이션: 더스트 제로 — AI 작업 인수인계

기준 빌드: **10.22-g** (2026-10-22). 이 문서와 `README.txt`를 먼저 읽고 작업을 시작해 주세요.
**밸런스에 닿는 작업**(수치·적·보상·해금·새 콘텐츠·성장 공식)이면 `BALANCE.md`도 먼저 읽고, 끝날 때 같은 작업 안에서 갱신하세요(5장 7번).

## 1. 프로젝트 한 줄 요약
가전을 의인화한 수집형 타일 디펜스(명일방주식 배치)와, 리더 하나를 움직이는 서바이벌 모드(대청소)를 합친 게임입니다. 모바일 세로 화면용 **HTML5 Canvas + 순수 JS 단일 파일**이고, 라이브러리와 빌드 도구는 없습니다. 밸런스 수치는 전부 엑셀 테이블에서 옵니다. 콘셉트는 **귀여운 SD(전투·로비) + 고퀄 일러스트(정보창·등장 연출)**입니다.

## 3. 데이터 흐름 (가장 중요)
- 지금까지는 **`gen_tables.py`가 원본**이었습니다. 수치를 바꿀 때 이 파일을 고치고 실행해서 엑셀과 data를 같이 다시 만들었습니다.
- `gen_tables.py`를 실행하면 `tables/*.xlsx`를 **덮어씁니다**. 엑셀에서 손으로 고친 값이 있다면 실행 전에 `gen_tables.py`에 옮겨 적거나, `build.py`만 쓰세요.
- 두 방식을 섞지 말고 작업마다 **원본을 하나만** 정하세요. 정했으면 README 맨 아래 변경 기록에 적어 주세요.
- **10.16-f는 `gen_tables.py`가 원본**이었습니다(엑셀은 그 결과와 같음). 적 HP 보정 `HP_K_LATE`(4챕터부터)는 `tools/sim` 결과를 옮겨 적은 값입니다.
  - 웨이브·맵을 바꾸면 그 챕터는 `node tools/sim/run.mjs <시작> <끝> '{"tune":1}'` → 챕터 중앙값으로 `HP_K_LATE` 갱신 → `verify.mjs`로 확인하세요.
  - 기준 계정 곡선은 `REF_LV_PTS`. 바꾸면 HP·과열 피해·권장 레벨이 같이 움직이고, `tools/econ_model.py`로 진행 일수를 다시 보세요.
- 화면 문구는 `string_ko` 테이블의 키로 씁니다. 코드에서는 `T('unit.vac.name')`처럼 꺼냅니다.
- 조정할 수 있는 수치를 새로 만들면 하드코딩하지 말고 `config` 키로 추가합니다. `xlsx_io.py`의 CONFIG_NOTE에 설명도 한 줄 적습니다.
- `gen_tables.py`를 고친 뒤에는 config 키가 빠지지 않았는지 이전 결과와 비교해 보세요. 예전에 줄 끝 `#` 주석 때문에 키 두 개가 사라진 적이 있습니다.

- **서브 콘텐츠 방향(10.18-h, 사용자와 정함):** 메인은 스테이지. 서브는 주요 파밍처가 아니고 '일회성 보상 + 하루치 유료 재화'. 하루치는 미니게임 셋 중 골라서(한 곳 깊게 / 조금씩) 채우는 선택형 숙제 → 오늘의 청소 일지. 실시간 온라인 협동은 인력상 어려워 봇 협동전으로, 파트너 스타일은 내가 고름(고점 낮지만 초반에 째는 친구 / 고점 높지만 초반 답답한 친구). 서브 콘텐츠는 일지 3개(대청소·협동·리그) + 일회성 1개(타워)로 더 늘리지 않는 쪽을 권함.
- **먼지 타워(10.18-g, 사용자와 정함):** '무한의 탑' = 주요 재화를 주는 1회성 클리어 던전. 층마다 매번 뽑는(상점) 방식은 빼고, 계정 성장은 그대로 반영. 연전(체력 이어짐) 방식은 쓰지 않음(빌드를 잘못 짜면 끝나는 부담). 보너스 목표는 깬 층에 다시 들어가 딸 수 있게. 전투는 리그 판 재사용, 층마다 '집 사정' 규칙으로 편성을 바꾸게 함.
- **1-1 흐름·거실 맵(10.18-f, 사용자와 정함):** 거실 맵 (0,1) 칸은 1번 입구 스폰 경고에 가려 안 보여서 배치 불가로. 1-1 발전기 안내 칸은 4,3. 에어컨 뒤 대기가 길고 전력이 남아 루즈해서 곰팡이(선풍기 안내)를 24초로 당김. 1-1 웨이브를 다시 고칠 때는 `tools/sim/tut_timeline.mjs`(안내 단계마다 게임 시각·전력 기록)으로 빈 구간이 없는지 확인 권장.
- **리그 방향(10.18-c, 사용자와 정함):** 본편 실시간 전투가 피곤해서 '판짜기는 내 속도로, 전투는 지켜보기'인 오토배틀러로. 준비 시간 제한 없음(혼자 하는 모드라 TFT 타이머 불필요), 전투 기본 2배속, 8라운드(한 판 4~5분). 계정 성장은 눌러서(최대 +30%) 반영하고 전용장비는 그대로 — 판 안 승부는 운영, 어느 단계까지 깨느냐는 성장. 상점 가전은 편성 6종(많이 모은 계정이 오히려 합체가 어려워지는 문제를 피함).
