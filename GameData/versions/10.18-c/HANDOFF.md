# 오퍼레이션: 더스트 제로 — AI 작업 인수인계

기준 빌드: **10.18-c** (2026-10-18). 이 문서와 `README.txt`를 먼저 읽고 작업을 시작해 주세요.

## 1. 프로젝트 한 줄 요약
가전을 의인화한 수집형 타일 디펜스(명일방주식 배치)와, 리더 하나를 움직이는 서바이벌 모드(대청소)를 합친 게임입니다. 모바일 세로 화면용 **HTML5 Canvas + 순수 JS 단일 파일**이고, 라이브러리와 빌드 도구는 없습니다. 밸런스 수치는 전부 엑셀 테이블에서 옵니다. 콘셉트는 **귀여운 SD(전투·로비) + 고퀄 일러스트(정보창·등장 연출)**입니다.

## 3. 데이터 흐름 (가장 중요)
- 지금까지는 **`gen_tables.py`가 원본**이었습니다. 수치를 바꿀 때 이 파일을 고치고 실행해서 엑셀과 data를 같이 다시 만들었습니다.
- `gen_tables.py`를 실행하면 `tables/*.xlsx`를 **덮어씁니다**. 엑셀에서 손으로 고친 값이 있다면 실행 전에 `gen_tables.py`에 옮겨 적거나, `build.py`만 쓰세요.
- 두 방식을 섞지 말고 작업마다 **원본을 하나만** 정하세요. 정했으면 README 맨 아래 변경 기록에 적어 주세요.
- **10.16-f는 `gen_tables.py`가 원본**이었습니다(엑셀은 그 결과와 같음). 적 HP 보정 `HP_K_LATE`(4챕터부터)는 `tools/sim` 결과를 옮겨 적은 값입니다.
  - 웨이브·맵을 바꾸면 그 챕터는 `node tools/sim/run.mjs <시작> <끝> '{"tune":1}'` → 챕터 중앙값으로 `HP_K_LATE` 갱신 → `verify.mjs`로 확인하세요.
  - 기준 계정 곡선은 `REF_LV_PTS`. 바꾸면 HP·과열 피해·권장 레벨이 같이 움직이고, `tools/econ_model.py`로 진행 일수를 다시 보세요.
- 화면 문구는 `string_ko` 테이블의 키로 씁니다. 코드에서는 `T('unit.vac.name')`처럼 꺼냅니다.
- 조정할 수 있는 수치를 새로 만들면 하드코딩하지 말고 `config` 키로 추가합니다. `xlsx_io.py`의 CONFIG_NOTE에 설명도 한 줄 적습니다.
- `gen_tables.py`를 고친 뒤에는 config 키가 빠지지 않았는지 이전 결과와 비교해 보세요. 예전에 줄 끝 `#` 주석 때문에 키 두 개가 사라진 적이 있습니다.

## 5. 작업 규칙
1. **부분 수정만 하세요.** index.html을 통째로 다시 출력하지 말고, 바꿀 함수나 블록만 찾아서 교체합니다. 통째로 다시 쓰면 중간이 잘리거나 다른 곳이 바뀔 위험이 큽니다.
2. **빌드 번호:** 바꿀 때마다 `10.16-e` 같은 문자열을 **파일 전체에서 한꺼번에** 올립니다. 화면 표시와 캐시 방지용 `?v=`가 함께 바뀌어야 합니다(현재 5곳: 설정 화면 표시, `tables.js?v=`, `json?v=`, 배경음악 `?v=` 2곳).
   - CSS의 `/* 10.16-f … */` 같은 주석은 그 기능이 들어간 빌드 표시라 올리지 않습니다(통째 치환할 때 주석은 빼세요).
   - 아이콘 `art/icon/*.webp?v=10.18-a`는 아이콘 파일 버전입니다(17곳, HTML 탭·지갑 + JS `ico()`). 아이콘 그림을 바꿀 때만 올립니다.
   - 일러스트(`art/<id>_*.webp`) 주소에는 `ART_V`(index.html)가 붙어요(10.16-n). 그림을 바꿀 때 올리면 캐시된 옛 그림이 안 나와요. 빌드 번호를 통째로 바꿀 때 같이 바뀌어도 문제는 없어요.
   - JS 주석의 `10.16-m` 같은 표시는 그 기능이 들어간 빌드라 통째 치환에서 빼세요.
3. **화면 문구:** 한국어, "~요" 말투로 짧게 씁니다. 기획 용어보다 플레이어가 알아듣는 말을 씁니다.
4. **README 갱신:** 기능을 추가하면 README에 해당 기능 섹션을 추가하거나 고칩니다. 맨 아래 변경 기록에 한 줄 남깁니다.
5. **확인:** 크롬에서 `index.html`을 직접 열어 확인합니다(압축을 **전부** 풀고 열어야 함. 일부만 풀면 'Failed to fetch' 안내가 뜸). 처음부터 하려면 홈 오른쪽 위 "게임 초기화"를 3초 안에 두 번 누릅니다. 빌드 번호는 [설정]에 있습니다.
6. **회사 자료:** 개인 프로젝트입니다. 회사 자료나 IP는 쓰지 않고 원칙 수준으로만 참고합니다.

- 75스테이지 `verify.mjs` 한 번은 환경에 따라 수 분~수십 분 걸립니다(10.16-l 작업 환경에서는 5스테이지 약 7초). 클라우드 환경의 playwright는 설치된 크로미움 버전에 맞춰야 해요(예: 크로미움 1194 → `playwright@1.56.1`). 비교할 때는 폴더를 복사해서 두 설정을 동시에 돌리면 빨라요.
