[신규 가전 (10.16-f)]
  다리미(SR, 근접): 저지 1, 강타. 평타·스킬 모두 방어 무시. 스킬 '스팀 프레스' = 앞쪽 범위 피해 + 기절.
  가스레인지(SR, 원거리·지상만): 평타 자리에 불길(지속 피해), 스킬 '센 불' = 적이 몰린 곳에 큰 화염 지대.
  보일러(SSR, 원거리): 평타가 방어를 깎고 화상. 스킬 '고압 스팀' = 사거리 안 모든 적 피해·방어 크게 깎기·둔화. 방어가 0 밑으로 내려가면 피해가 더 들어가요(하한 config armorMin).
  셋 다 전용장비 · 대청소 동료(보일러는 리더에 붙는 지원형) · SD · 일러스트가 있어요. 소환 확률: SSR 3%(3종) · SR 17%(5종) · R 80%(4종).

[밸런스 기준 (10.16-f)]
  '기준 계정' = 그 스테이지에 처음 도전하는 무과금 플레이어의 평균 편성(stage.refLv · refStar · refGear).
    Lv: 1-1 Lv.1 → 3-5 Lv.15 → 6-5 Lv.25 → 9-5 Lv.31 → 12-5 Lv.36 → 15-5 Lv.40(★4). SR은 돌파 1단계, SSR은 2단계 낮게 봄. 공용장비 +0% → +40%.

[전투 중 강화 · 멀티탭]
  배치가 다 찬 뒤 남는 전력을 쓰는 곳. 놓인 가전을 누르면 그 판에서만 2단계(비용 ×1.0) → 3단계(×1.5)로 강화.
  3단계는 근접 저지 +1, 원거리 사거리 +0.4칸, 지원 범위 증가 같은 보너스. 철수하면 배치+강화에 쓴 전력의 절반을 돌려받음.
