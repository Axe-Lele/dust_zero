오퍼레이션: 더스트 제로 - 플레이 테스트 묶음
=============================================

[바로 플레이]
  index.html 을 더블클릭하면 브라우저(크롬 권장)에서 바로 실행됩니다.
  인터넷이 없어도 돌아가고, 연결돼 있으면 글꼴만 더 예쁘게 나옵니다.
  진행 데이터는 그 브라우저에만 저장됩니다. 처음부터 하려면 홈 오른쪽 위 "게임 초기화"(3초 안에 두 번 누름, [설정] 안에도 있음). 빌드 번호는 [설정] 안에 있습니다.

[밸런스 수정 = 엑셀]
  1) tables/ 폴더의 엑셀을 열어 수정하고 저장 (엑셀을 닫지 않아도 됩니다)
  2) 명령창에서 이 폴더로 이동한 뒤:   python tools/build.py
     -> data/*.json 과 data/tables.js 가 새로 만들어집니다
  3) 브라우저 새로고침

  * 처음 한 번만:  pip install openpyxl   (파이썬 3 필요)
  * 스킬 설명 문구는 skill_param 수치로 게임이 자동으로 채웁니다.
    문구 자체를 바꾸려면 string_ko 시트에서 {pullRadius} 같은 자리표시자를 남겨 두고 고치세요.

[엑셀 규약]
  - 시트 이름 = 테이블 이름. 파일 이름은 정리용일 뿐 상관없습니다.
  - '#'으로 시작하는 시트는 변환에서 제외됩니다 (메모, 검산용으로 자유롭게 쓰세요).
  - 1행 = 컬럼 키(바꾸지 마세요), 2행 = 설명(무시됨), 3행부터 데이터.
  - A열 값 앞에 '#'을 붙이면 그 행은 빠집니다. 행을 지우지 않고 잠시 끌 때 쓰세요.
  - 배열 값은 [1, 6, 10] 처럼 대괄호로 적습니다 (config의 starLifeMin).
  - 맵 경로는 map_entrance.path 에 "0,2 > 1,2 > 1,8 > 3,8 > 3,9" 형식으로 적습니다.

[전투 중 강화 · 멀티탭]
  배치가 다 찬 뒤 남는 전력을 쓰는 곳. 놓인 가전을 누르면 그 판에서만 2단계(비용 ×1.0) → 3단계(×1.5)로 강화.
  3단계는 근접 저지 +1, 원거리 사거리 +0.4칸, 지원 범위 증가 같은 보너스. 철수하면 배치+강화에 쓴 전력의 절반을 돌려받음.
  멀티탭(덱 위 버튼)으로 배치 칸을 8 → 9 → 10대까지 늘릴 수 있음(2,000W / 3,500W).
  웨이브 후반일수록 적 HP가 올라(wave.hpMul, 마지막 웨이브 ×3) 강화가 필요해집니다. 1-1 튜토리얼 스테이지는 제외.
  수치는 02_Unit.xlsx 의 unit_boost 시트, config 의 multitapCost, 04_Stage.xlsx wave 시트의 hpMul.

[로비 (방)]
  홈은 방 한 칸. 보유한 가전이 모두 돌아다니며 바닥에 생기는 먼지를 치웁니다(모을수록 북적임).
  가전을 누르면 대사, 먼지를 누르면 바로 치워짐. 버튼은 방 위에: 왼쪽 위 출석부·자동 청소, 오른쪽 위 설정, 아래 대청소 모드·다음 스테이지.

[출석부]
  접속 시(그날 처음) 팝업. 7칸 순환(연속 아니어도 한 칸씩): 크리스탈 50 / 코인 5,000 / 크리스탈 50 / 부품 각 10 / 크리스탈 50 / 코인 10,000 / 크리스탈 200.
  05_Reward.xlsx 의 attendance 시트(보상은 reward_group 9101~9107). 첫 안내(가이드) 중에는 뜨지 않고 끝난 뒤에 뜹니다.

[무과금 보상 조정 (10.15-b)]
  상점 효율(10회 소환 ≈ ₩30,000)에 맞춰 무과금 크리스탈을 하루 약 900 → 약 350~450(출석 50 · 대청소 150 · 자동 청소 60~170 · 광고 90)으로 줄였습니다.
  출석 매일 300 → 7일 합계 350, 대청소 시간 보상 하루 최대 300 → 150, 자동 청소 시급 15~25 → 5~7,
  첫 클리어 100/300 → 50/150, 챕터 별 15개 보상 300·450·600 → 150·225·300. 시작 지급 1,500(첫 10회 소환)은 유지.

[배경음악]
  audio/ 폴더: lobby.mp3(로비) · battle.mp3(스테이지 전투) · survival.mp3(대청소 모드). Suno로 만든 곡.
  파일 = 인트로(처음 한 번만) + 반복 구간. 반복 시작·끝은 음악적으로 가장 비슷한 지점을 자동으로 골랐고,
  끝 2.5~3초를 반복 시작 직전과 섞어 이음새를 없앰. 반복 구간: 로비 9.9~29.6초(19.7초) · 전투 11.4~71.4초(60초) · 대청소 11.8~150.7초(139초).
  재생은 Web Audio로 정확한 지점에서 반복(파일을 직접 연 경우엔 <audio>로 대체). 첫 터치 뒤부터 재생, 화면 전환 시 교차 페이드.
  음량·음소거는 홈 [설정]. 곡을 바꾸면 반복 지점(코드의 BGM_LOOP)도 새로 잡아야 함.

[효과음 · 칩튠]
  효과음은 파일 없이 코드로 합성(Web Audio). 버튼 터치, 배치, 강화, 멀티탭, 스킬, 적 처치, 청결도 감소, 과열 경보, 보스 등장,
  승리·패배, 레벨 업, 돌파·영입, 소환(등급별), 출석 도장, 보상·구매, 광고 완료, 방 캐릭터·먼지 터치, 대청소(레벨 업 · 먼지 조각 · 피격 · 포자) 등 26종.
  칩튠 BGM: 대청소 모드용 150 BPM 16마디 곡(코드로 작곡, 박자 단위 반복이라 이음새 없음). [설정]의 "대청소 음악"에서 Suno 곡 / 칩튠 선택.
  [설정]에 효과음 음량·음소거. 소리 정의는 코드의 SFX_DEF, 칩튠 악보는 MEL·CHIP_CHORDS.

[조각 · 돌파]
  가전마다 조각이 있음. 이미 가진 가전을 또 뽑으면 그 가전 조각(R 10 / SR 15 / SSR 25). ★5까지 다 채운 뒤 중복은 코인 1,000.
  돌파는 가전 상세 창에서 조각+코인으로 직접: ★1 조각 10·코인 2,000 → ★5 조각 50·코인 40,000. 돌파 1당 능력 +12%.
  레벨 상한: ★0 Lv.20, 돌파마다 +5 (★5 Lv.45). 상한에 닿으면 레벨 업 버튼이 "돌파 필요"로 바뀜.
  없는 가전도 조각을 모으면 영입(R 20 / SR 30 / SSR 50). 도감 타일에 "돌파 가능"·"영입 가능" 표시.
  조각 획득처: 중복 소환, 상점 일일 탭 "오늘의 조각"(광고 무료 1회 + R/SR/SSR 크리스탈 구매, 매일 가전이 바뀜),
  대청소 보상 판(버틴 1분마다 리더 조각, 최대 5), 시즌 패스(무료 7·14·21·28레벨 에어컨 조각, 프리미엄 29레벨 세탁기 조각).
  02_Unit.xlsx 의 unit_star 시트, config 의 lvCapBase · dupeShards · shardRecruit · survShard*, 조각 아이템은 item 300번대.

[시즌 패스]
  홈 오른쪽 위 [시즌 패스] 버튼. 28일 시즌(1시즌 2026-10-12 시작, 이후 같은 길이로 순환), 30레벨, 레벨마다 무료 줄 / 프리미엄 줄 보상.
  1레벨은 시작하자마자 받음. 프리미엄 패스(₩11,000 테스트 결제, 상점 패키지 탭에도 있음)를 사면 지난 레벨 프리미엄 보상도 바로 받을 수 있음.
  프리미엄 줄: 크리스탈 합계 1,420 · 15레벨 SR 전자레인지 · 30레벨 SSR 세탁기. 무료 줄: 코인·부품, 5레벨마다 크리스탈 30.
  패스 경험치: 첫 클리어 +100 · 다시 클리어 +30 · 대청소 30초마다 +10(최대 80) · 출석 +50 · 광고 +10. 크리스탈 150으로 1레벨 구매 가능.
  레벨·보상은 08_Shop.xlsx 의 pass_level 시트(보상 reward_group 33000·34000번대), 경험치·시즌은 config 의 pass*.

[상점 · BM (테스트)]
  하단 [상점] 탭 또는 상단 크리스탈 옆 + 버튼. 탭 3개: 크리스탈 / 일일 상점 / 패키지.
  현금 상품은 테스트 결제창만 뜨고 실제 결제는 없음(확인하면 바로 지급, 누적 테스트 결제액이 상점 아래에 표시).
  무료 보상은 모두 광고 시청(테스트용 5초 화면). 광고 제거 패스를 사면 시청 없이 바로 받음.
  크리스탈 상품은 첫 구매 2배, 가전 관리 구독은 30일간 상점에서 매일 크리스탈 100 받기.
  상품·가격·제한·보상은 08_Shop.xlsx 의 shop_product 시트(보상은 05_Reward.xlsx reward_group 30000번대).

[처음 시작 안내]
  새 계정(또는 게임 초기화) 첫 실행 시 화면을 어둡게 가리고 1-1 출동 버튼만 누를 수 있게 안내합니다.
  1-1을 처음 깨면 결과 화면 → 로비 → 가전 탭 → 청소기 → 레벨 업 → 닫기 → 홈 → 1-2 순서로 안내합니다.
  말풍선의 "안내 건너뛰기"로 언제든 끌 수 있습니다. 순서·대상·문구는 04_Stage.xlsx 의 guide 시트(guide.* 문구 키).

[튜토리얼]
  스테이지가 아니라 '처음 하는 전투들'에 규칙을 하나씩 안내합니다. 전투 1판에 1묶음씩 순서대로 열리고,
  그 판에 못 본 안내는 다음 판으로 넘어갑니다. 보스·주방·욕실 안내는 그 전투를 처음 할 때 나옵니다.
  이미 진행한 저장 데이터도 다음 전투부터 처음 묶음이 나옵니다. 한 번 본 안내는 다시 안 뜹니다.
  다시 보려면 홈 [설정] → "튜토리얼 다시 보기". 조건은 04_Stage.xlsx 의 tutorial 시트, 문구는 string_ko 의 tut.* 키.

[대청소 모드 (프로토타입)]
  하단 [콘텐츠] 탭(또는 홈의 "대청소 모드" 버튼)에서 입장. 1-1 클리어 후 열립니다(content_unlock 의 survivor 행 cond 로 조정).
  쓰러질 때까지 버티는 무한 모드. 2분마다 보스(먼지 대왕 → 기름 대왕 → 곰팡이 여왕 순환).
  적 이동 속도는 시작부터 분당 +7%(최대 1.8배), 2:30부터 HP·피해가 분당 복리로 강해집니다.
  1:40부터 원거리 적 '포자 곰팡이'가 거리를 두고 포자를 쏩니다(옆으로 비켜 피함).
  레벨업 경험치는 후반으로 갈수록 가파르고, 뽑을 강화가 다 떨어지면 회복 대신 보너스 코인만 나옵니다(무한 회복 없음).
  버틴 시간 구간(1:00, 2:00 … 15:00)을 그날 처음 넘기면 크리스탈. 부품·코인은 하루 3판.
  리더(청소기·로봇청소기·에어컨)를 골라 화면을 끌거나 WASD·방향키로 이동, 공격은 자동.
  레벨업마다 편성의 가전이 동료로 합류(컴퓨터·선풍기·발전기는 리더에 붙음)하거나 강해집니다.
  협동기: 청소기+선풍기, 에어컨+냉장고, 로봇청소기+발전기 (리더 무기 Lv3 이상 + 해당 동료 최대 레벨).
  수치는 07_Survivor.xlsx(surv_reward = 시간 구간별 크리스탈)와 config 의 surv* 항목.

[테스트 팁]
  - 홈의 "테스트용 +1시간" 버튼으로 자동 청소 누적을 빨리 확인할 수 있습니다.
  - 전투 중 1×/2× 버튼으로 배속.
