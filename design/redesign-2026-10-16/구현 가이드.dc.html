오퍼레이션: 더스트 제로 — UI 구현 가이드

디자인 시안 기준 · Unity 미검증수치는 1080×1920 기준 px · 괄호 안은 390pt 목업 기준

아래 값은 HTML 시안에서 정한 것으로, Unity에서는 아직 확인하지 않았습니다. 기기 테스트(iPhone SE / 15 Pro Max / Galaxy S·Z Fold 접은 상태) 뒤 조정할 항목은 ‘검증 필요’로 표시했습니다.

2. 글꼴 · 크기 · 굵기

글꼴 후보: Pretendard(UI 전체, OFL) + Jua(제목·큰 버튼, OFL). 대안은 Pretendard 단일 사용(디스플레이는 ExtraBold). TMP 폰트 에셋은 KS X 1001 완성형 2,350자 + 영문·숫자·기호로 만들고, 그 밖의 글자는 Dynamic 폴백 에셋으로 처리합니다. 숫자는 고정폭(tnum) 또는 Monospace 옵션을 켭니다.

3. 여백 · 버튼 · 패널 · 아이콘 규칙

  • 간격 단위 4pt: 4 / 6 / 8 / 10 / 12 / 16 / 24. 화면 좌우 여백 12pt(33px), 패널 안쪽 14–16pt.
  • 최소 터치 영역 44×44pt(121px). 아이콘은 24–27pt로 그리되, 터치 영역은 투명 Image(Raycast Target)로 44pt 이상 확보합니다.
  • 버튼 높이: 주요 버튼 56–72pt · 보조 버튼 44–56pt · 아이콘 버튼 44pt. 모서리는 높이의 약 30%(14 / 18 / 20pt).
  • 버튼 입체감: 그라데이션·광택 대신 아래쪽 단색 두께 3–5pt(Edge 색). 누르면 Y −3pt 이동 + 두께 2pt, 시간 60ms.
  • 패널: Panel 색 + 모서리 16–28pt, 그림자는 아래쪽 단색 2pt(Ink 12%)만 사용합니다. 테두리·광택·그라데이션은 넣지 않습니다.
  • 아이콘: 둥근 꼭짓점의 채워진 아이콘, 선 굵기 2pt 상당. 한 색만 쓰고, 상태는 아이콘이 아니라 배지와 바탕색으로 구분합니다. 시안의 아이콘은 임시이며 자체 아이콘 세트로 교체가 필요합니다.
  • 배지: 알림은 빨간 점 18pt + 흰 테두리 2pt, 정보 배지(Lv.7, 무료)는 둥근 직사각형 높이 16pt.
  • 숫자: 9,999까지는 전체, 1만 이상은 K/M/B로 유효숫자 3자리. 길게 누르면 툴팁으로 전체 값을 보여 줍니다.
  • 긴 한글: 카드는 1줄 말줄임. 상세 화면은 2줄까지 쓰고, 넘치면 TMP Auto Size(최소 크기 −2pt)를 적용합니다. 버튼 문구는 8자 이내를 원칙으로 합니다.

4. Canvas · Safe Area · 앵커

  • Canvas Scaler: Scale With Screen Size, Reference 1080×1920, Match 0.5(검증 필요: 긴 화면에서 0.6–1.0 비교). 목업 1pt = 2.77px.
  • SafeAreaRoot: Screen.safeArea를 앵커 min/max에 반영하는 스크립트를 두고, 해상도·회전이 바뀔 때마다 다시 계산합니다. 배경과 하단 바 바탕은 SafeArea 밖까지 깔고, 터치 요소만 SafeArea 안에 둡니다.
  • 홈 인디케이터 영역(하단 약 34pt)에는 버튼을 두지 않습니다. 하단 바 바탕만 그 영역까지 늘립니다.
  • 긴 화면(19.5:9 이상): 방(홈)과 전장(전투)이 남는 세로 공간을 차지합니다. 짧은 화면(16:9): 전장 칸 크기를 min(가로 ÷ 7, 남은 세로 ÷ 10)으로 줄입니다. 시안 오른쪽 위 Tweaks에서 360×780 / 430×932로 바꿔 볼 수 있습니다.
  • 폴더블·태블릿: 콘텐츠 최대 폭 600pt로 가운데 정렬하고, 좌우는 배경으로 채웁니다(추측: 지원 기기 범위 확인 필요).

6. 스크롤 영역

  • 홈: 스크롤 없음(고정). 방은 가로로 넓힐 경우 좌우 패닝(선택 사항, 추측).
  • 스테이지 탭: 세로 ScrollRect, 챕터 머리말 고정(sticky). 현재 스테이지로 자동 스크롤합니다.
  • 가전 · 소환 · 상점 목록: 세로 ScrollRect + 화면에 보이는 항목만 만드는 재사용 셀(오브젝트 풀).
  • 바텀 시트: 내용이 시트 최대 높이(화면의 80%)를 넘을 때만 안쪽 스크롤을 씁니다.
  • 전투: 스크롤 없음. 카드가 6장 이상이면 CardRow만 가로 스크롤(추측).
