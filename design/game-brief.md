# Clean Girls / Dust Zero

Existing-game port, not a new game design. Recreate the portrait 2D appliance-themed
tower-defense game plus its five-minute survivor mode from GameData/original_index.html.
Preserve the Excel-driven balancing, units, stages, growth, rewards and tutorial.
The first playable milestone is one complete defense stage followed by a working
results screen and return to the lobby. Full requirements: docs/DUSTZERO-PORT-BRIEF.md.
