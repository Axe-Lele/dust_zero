## 이 보고서가 보지 못하는 것

- **글자의 너비·높이** — 두 쪽이 서로 다른 것을 잰다. CSS 의 Range 는
  advance 박스(사이드베어링 포함), TMP 의 textBounds 는 칠해진 자리만이다.
  그래서 우리 쪽 dw 가 늘 음수로 나오는데 글꼴이 좁은 게 아니다.
  **글자는 맞춰진 모서리로 비교한다** — 왼쪽 정렬은 왼쪽, 오른쪽은 오른쪽,
  가운데는 중심. 정렬은 ink 가 상자 안에서 앉은 자리로 읽는다. 한 기준으로
  고정하면 반대쪽 정렬이 너비 차이의 절반만큼 통째로 밀린 것으로 나온다.
  dy 는 세로 중심 차이다.
  표의 dw·dh 는 참고용이다.
- **글자가 없는 상자** — 판·아이콘·구분선은 글자로 못 맞춘다.
  `PAIRS` 에 적은 것만 본다. 지금은 상단바·하단바·전투 HUD 판 셋.
- **글자색** — 원본은 `color` 를 뽑아 두었지만 이식본 쪽은 TMP 의 색을
  아직 안 적는다. 그래서 배경색만 비교한다.
- **보드와 아레나** — 이식본은 카메라로 그려서 UI 상자가 없다.
- 원본에만 있는 글자 수가 큰 화면은 그만큼 못 본 것이다.
